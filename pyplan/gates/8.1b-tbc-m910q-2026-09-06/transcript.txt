=== a fault this run caused, and what it proved ===

Before the login the TBC stack would not start: mangosd logged

    Could not connect to MySQL database at tbc-db: Unknown MySQL server host 'tbc-db' (-3)

Cause: a bare `docker start tbc-db` earlier in this session had started the container while its
compose network did not exist, so it ran with NO network attached while `docker ps` said "Up" and
healthy. Fixed with `docker compose up -d --no-deps --force-recreate tbc-db`, which reattached it.

Worth recording because it is the exact shape of the bug this gate fixed an hour earlier: a
container that reads as up while the server behind it is unusable. With the change made at
769f56e8 the verdict for that state is `up` with `stable=False`, not a clean bill of health.
