clause 5 — an occupied port (FIRST ATTEMPT: the predicate did not match)
    $ python gate82a_rest.py port         # at ab631d36
    [00:16:25Z] the tab said: 'docker compose up -d --no-deps ... exited 1:
        ... Error response from daemon: failed to set up container networking:
        driver failed programming external connectivity on endpoint
        ac-worldserver (34fb00de9718): failed to bind host port
        127.0.0.1:7878/tcp: address already in use'
    AssertionError: the tab did not say what it undid

    blames_the_host_port() required "bind for", which is Docker's OLDER
    wording. Fixed at 2f3b3cf9.

    Aftermath worth recording: that failed bind left ac-worldserver created
    with its networking half-configured, and the next `compose up` STARTED
    that same container rather than recreating it — no network at all, could
    not resolve ac-database, exit 1, restart loop. 8.1a's verdict reported it
    correctly. The container was removed by hand and the install started clean.
