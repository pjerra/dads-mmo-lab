Adopt WoW Tortoise's databases as a finished import?

Folder: /home/pk/tortoise-server

These databases: tw_world, tw_logon, tw_char

This writes ONE row and nothing else. Into `tw_world`.`yulon_install` — the table this app's own import creates and writes at the end of a successful one, created here if it is not already there — goes a row recording that this install plan (8b60e764371f2293) finished. Nothing is imported, nothing is dropped, no user is created, no SQL file is streamed, and your characters, accounts and world are read only to learn which state they are in.

Yu'lon will treat these databases as a finished import from now on. It cannot check that the import finished; you are saying so. If it did not, the next press of Apply pending database updates will run the flagged files on an unfinished database.

The server must be STOPPED first — press Stop on the Server tab, and leave it down until this has finished. A running world server holds these tables in memory and writes back over whatever it finds in them, so this press refuses while it is up. The database alone is started if it is down, and stopped again afterwards if this press was what started it; the world server is never started by this.
