TITLE: Apply database updates to WoW Tortoise?

Apply the database updates WoW Tortoise's install plan carries for a server that already exists?

Folder: /home/pk/tortoise-server

This applies 3 SQL step(s), the whole of character updates, into this install's databases:

    src/tortoise-wow/sql/character_updates/20260708055500_ai_playerbot_random_bots_index.sql
    src/tortoise-wow/sql/character_updates/20260731160000_guild_bank_money_unsigned.sql
    src/tortoise-wow/sql/character_updates/20260812142512_character_inventory_copy.sql

Nothing else in the install plan is re-run. Your databases keep the completion marker they already have — this press writes no new one — and your characters, accounts and world are not otherwise written, and read only to learn which state they are in. If they do not read as a finished import this press stops and says so: it will not import them, and it will not clear anything.

The server must be STOPPED first — press Stop on the Server tab, and leave it down until this has finished. A running world server holds these tables in memory and writes back over whatever it finds in them, so this press refuses while it is up. The database alone is started if it is down; the world server is never started by this.

If a file cannot be applied the press stops on it and says which file and why — nothing after it runs. The one refusal known to be reachable is a guild bank balance that has gone negative, which the column type these files set cannot hold.
