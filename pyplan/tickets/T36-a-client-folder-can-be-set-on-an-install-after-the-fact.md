## What is true today

- `state.json` records `client_dir` per install (`yulon/state.py::KnownInstall`). It is filled exactly twice: at Install for the games whose catalog entry says `requires_client_dir` (TBC, Vanilla, Tortoise — extraction reads the client), and at "Use existing…". WotLK's Install never asks, so its records carry `client_dir: null`.
- The record is read once, when the tab is built: `main.py:300 add_controller(game, server_dir, client_dir, wsl_distro)` → `ControllerServices.for_*(entry, server_dir, client_dir, wsl_distro)` (`controller_view.py:~661`), and the value is baked into the tab's seams — the module applier's `client_dir=_client_dir_for_addons(client_dir)` (`controller_view.py:~1826`; refuses `None`, and a folder with no `Interface/`), the Steam seam (`:~882`), the Play tab.
- Nothing on any tab sets or changes it. A WotLK install can never receive an addon a manifest's `client` step writes (`manifests/wow-wotlk`'s keg); an adopted Tortoise install without a client cannot get `/tbm`; a moved client cannot be re-pointed. The only route is editing `state.json` by hand.
- The preflight's client checks exist as a function: `yulon/catalog/families/clientdir.py::validate(client_dir, spec, ...)` — `Data/` and its MPQ archives to the expected depth, the locale folder, the repack warning, free space — the same checks the Install press prints as `[pass]`/`[warn]`.

## Definition of done

1. **A row on the Server tab** under the status lines: `Client folder: <path>` or `Client folder: none — addons and Play need one` , with a button `Change client folder…` (label `Set client folder…` when none is recorded) and, when one is recorded, `Forget client folder`. Visible for every game; hidden for a WSL-distro install only if the client folder would be inside the distro (it is not — a client is a host path — so visible there too; say so in a comment).
2. **The press** opens the existing directory picker (`_qt_dir_picker`, the same seam the Catalog uses, so tests replace it), then validates through `clientdir.validate()` with the entry's `ClientSpec` (the catalog's `client` block — find how the Install preflight obtains it and reuse that): a folder with no `Data/` or no archives is **refused** with the check's own sentence, nothing written; warnings (repack, locale) are **shown, not blocking**, in a `QMessageBox.question` "Use it anyway? <the warnings>" answered through `said_yes()`. A folder without `Interface/` is accepted (the addon writer refuses that case itself with its own sentence — do not duplicate the rule) but the row says `no Interface/ folder yet — start the game once before installing addons`.
3. **The write** goes through a live-`AppState` seam the way T34's forget does: `main.py` gains `_remember_client_live(game, server_dir) -> Callable[[Path | None], None]` beside `_forget_live_record()` — it finds the `KnownInstall`, replaces it with `dataclasses.replace(install, client_dir=…)` via `state.remember()`, `save_state()`; on `OSError` the previous record is put back and the error re-raised; `ControllerServices` gains a `set_client_dir: Callable[[Path | None], None] | None` seam `main.py` fills (default `None` → the row's buttons are hidden, as `uninstall is None` hides Uninstall). No new write function in `state.py` — `remember()` is the existing one — so `pyplan/write-ledger.md` gets **no new row**; say so in the report.
4. **After the write the tab is rebuilt**, not patched: the value is baked into a dozen seams at construction, and threading a mutable client dir through each is the wrong shape. The view emits a new signal `client_dir_changed(str game, object server_dir, object client_dir)`; `main.py` connects it to: drop this tab (the same path `uninstalled` takes) and `add_controller(game, server_dir, new_client_dir, wsl_distro)` again, selecting it. `Forget client folder` writes `None` and rebuilds likewise. Tests in `test_controller_view.py`: the row's three states (none / recorded / recorded without `Interface/`); a refused folder writes nothing and shows the sentence; a warned folder writes only after Yes (an `int`-returning fake — T33); the seam called with the picked path, then `client_dir_changed` emitted; `OSError` from the seam shows the error and emits nothing; `set_client_dir is None` hides the buttons. In `test_main.py`: `_remember_client_live` replaces the record and keeps `server_dir`/`wsl_distro`; a failing save restores the old record. Mutation named per test.
5. **Play and addons read the new value** by construction (the rebuilt tab); one test proves it end to end: a tab built with `client_dir=None` refuses the addon step, `set_client_dir` + rebuild with a folder holding `Interface/` → the applier is constructed with that folder (`_client_dir_for_addons` returns it).

**Not in scope:** the Catalog tile's Install asking WotLK for a client (still not required); validating the client's *version* against the game beyond what `clientdir.validate()` already does; Steam entries (they rebuild with the tab).
